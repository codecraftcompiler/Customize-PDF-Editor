Offline PDF Editor – Flask & PyPDF2

A fully offline, GUI-based PDF manipulation tool built using Flask and PyPDF2, packaged as a standalone Windows executable via PyInstaller.
This project enables seamless PDF operations without internet connectivity, making it ideal for secure and internal environments.

✨ Key Features

Merge PDFs – Combine multiple PDF documents into one.
Rotate PDFs – Rotate pages by 90°, 180°, or 270°.
Crop PDFs – Interactive cropping with precise control.
Sort PDFs by SKU – Automatically reorder PDF pages based on Flipkart or Amazon SKU lists.
SKU Manager – Add, delete, and organize SKU IDs via an easy-to-use interface.
Compress PDFs – Reduce file size while maintaining quality.
Crop & Merge – Crop pages and merge them in one step.

🛠 Tech Stack

Backend: Python (Flask)
PDF Processing: PyPDF2, fitz (PyMuPDF)
Frontend: HTML, CSS, JavaScript
Packaging: PyInstaller (Windows executable)

💡 Highlights

Works completely offline for enhanced data privacy.
Drag-and-drop SKU management.
Optimized for fast processing of large PDFs.
Clean and user-friendly UI.
